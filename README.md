# Earth Tunnel

What if you jumped into a straight tunnel through the centre of the Earth? A first-person Three.js game with 5 missions.

Idealised model: PREM density (Dziewonski and Anderson 1981), computed gravity, RK4 integration at a fixed 0.1 s step. Vacuum diameter drop: about 38.2 min. Heat, rock pressure and shaft engineering are not modelled. The ledge-grab is a game rule, not physics.

Earth texture: NASA Blue Marble, via three.js examples.

Source is in `src/`. Build with `npm install && npx vite build`.
